Novato: 'escribe código'. Senior: 'aquí el contexto, estos los constraints, dame tests'.

La diferencia no es el modelo. Es el contexto que le das. 3 niveles: Nivel 1 (novato): 'Hazme una API REST en FastAPI'. Resultado: código genérico, sin auth, sin tests, no escala. Nivel 2 (intermedio): 'FastAPI + PostgreSQL + JWT auth + pytest'. Mejor, pero decisions implícitas. Nivel 3 (pro): Contexto completo: arquitectura, patterns del repo, conventions, edge cases. Prompt: 'Repo: [estructura]. Patterns: repository + service. Convenciones: types estrictos, docstrings Google. Edge cases: rate limit, idempotency. Genera: service + tests + migración.' Nivel 3 = código listo para merge. Ahorro: 2-4h por feature.
